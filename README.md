# 🏰 Amunì Tourism - Caccamo Experience

Benvenuti nel cuore della Sicilia. **Amunì Tourism** è un'esperienza digitale interattiva dedicata alla scoperta del Borgo di Caccamo e delle sue leggende, guidata dalla voce della **Castellana**.

## 🌟 Caratteristiche del Progetto
* **Avatar Interattivo**: Incontro con la Castellana di Caccamo, ricostruita digitalmente per narrare la storia del borgo.
* **Atmosfera Immersiva**: Un layout moderno in stile "Glassmorphism" con uno sfondo dinamico che cattura i colori del borgo.
* **AI-Powered Chat**: Un sistema di intelligenza artificiale (in fase di sviluppo) per dialogare con i custodi della storia.

## 🛠️ Tecnologie Utilizzate
* **HTML5 & CSS3**: Per la struttura e il design responsivo.
* **Python (anywhere )**: Utilizzato per la configurazione di flask,anthropic,stripe e costruire la knowledge della castellana in 5 lingue.
* **GitHub Pages**: Per l'hosting gratuito e la pubblicazione del sito live.
* **Stripe**:per i pagamenti

## 📂 Struttura del Repository
* `/img`: Contiene le immagini elaborate (Castello, Castellana, Monumenti).
* `/css`: File di stile per il layout e gli effetti visivi.
* `/bot`: Logica Python Anywhere per il "cervello" della Castellana (In corso).
